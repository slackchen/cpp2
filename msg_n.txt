- commands.cpp run --backend=native on Windows: try direct PE (hello) first, else Win64 asm+struct via g++ -c; SysV label only on POSIX
- VSCode extension.js: cpp2.run/cpp2.build now pass --backend=native by default
- native emitter fixes (both SysV/Win64 classes):
  * Paren expression case added (was "expression kind" crash)
  * branch_bool: empty-true target now emits inverted jump to false (was invalid "jl "/infinite loops)

  * Return in methods uses cur_sym_name_ (cur_fn_ null crash); new cur_sym_name_ member set in emit_func/emit_method
  * method calls: args pushed before this so rcx=this pops correctly
  * method-field assignment (balance += amount): compound ops read/store through this-pointer with address on stack; simple = stores via popped addr
  * precheck allows i64/string/double struct fields, contracts, inout/out params (v0 value semantics)
- tools/native_rt.c: pure builtins (cpp2_write/sys_exit/div0 via them), print_int removed (user programs own it)
- rt support.hpp: checked_mul negative*negative false-trap fixed; cpp2_write/write_char/exit extern "C"
- std/math.cpp2: abs/min/max/clamp/powi/isqrt/gcd/lcm (pure L3)
- results: native 9/24 examples pass (was 3), rest fail with explicit Unsupported reasons; headers 23/24 (zlib needs CPP2_LDFLAGS as before)
